# GP Clinic – Multi-Device Booking App

Private GP booking single-page app: React (Vite) front-end + Express back-end.

## Run locally
```bash
cd server && npm install && npm run dev     # API on http://localhost:3001
cd client && npm install && npm run dev     # App on http://localhost:5173
```

## Structure
- `client/` – React front-end (pages in `src/pages`, components in `src/components`)
- `server/` – Express API (routes in `routes/`, data in `data/`)
